# Java Collections e Stream API — Esercizi

Raccolta di esercizi Java dedicati a collezioni, ordinamento, ricerca, aggregazione e trasformazione dei dati. Il repository documenta la pratica svolta durante il percorso Full Stack LabForWeb.

## Competenze dimostrate

- utilizzo di `List`, `ArrayList` e `Map`;
- filtri, trasformazioni e raccolta con Stream API;
- ordinamento con `Comparator` e `Comparable`;
- ricerca di valori con `Optional`;
- method reference e lambda expression;
- modellazione di entità con classi Java;
- validazione di base nei setter;
- gestione di input da console.

## Esercizi inclusi

- calcolo e filtraggio delle medie degli studenti;
- ricerca di prodotti e ordinamento per prezzo;
- selezione di film in base alla durata;
- ordinamento di dipendenti e stipendi;
- confronto di libri tramite `Comparable`;
- conteggio della frequenza delle parole con `Map`;
- filtraggio delle città per popolazione;
- ricerca dell'atleta con il punteggio massimo;
- ordinamento delle automobili per anno.

## Tecnologie

- Java
- Collections Framework
- Stream API
- Eclipse project configuration

Il progetto è configurato con JDK 25 nell'ambiente Eclipse utilizzato durante gli esercizi.

## Struttura

- `src/com/esercizi/Main.java`: esecuzione degli esercizi;
- `src/com/esercizi/es*`: modelli usati dai diversi casi pratici.

## Esecuzione

```bash
git clone https://github.com/fabiozagaria/java-streams-exercises.git
cd java-streams-exercises
```

Importa la cartella come progetto Java in Eclipse o IntelliJ IDEA ed esegui la classe `com.esercizi.Main`.

## Natura del repository

Si tratta di un laboratorio didattico, non di un'applicazione production-ready. Gli esercizi sono raccolti nello stesso punto per mostrare la progressione nello studio delle API Java.

## Possibili miglioramenti

- separare ogni esercizio in una classe eseguibile;
- aggiungere test automatici;
- introdurre Maven per una build riproducibile;
- rimuovere i metadati specifici dell'IDE dal versionamento.
