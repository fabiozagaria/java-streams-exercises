# Contesto tecnico — Java Streams Exercises

Aggiornato: 2026-09-08

## Natura del repository
Laboratorio didattico su Collections Framework e Stream API, nato durante il percorso LabForWeb.

## Stato
- Contiene esercizi su `List`, `Map`, Stream, `Comparator`, `Comparable`, `Optional`, lambda e method reference.
- Non è un'applicazione production-ready.
- Il repository è principalmente storico e di consultazione.

## Miglioramenti possibili
Il README cita come possibili evoluzioni separazione degli esercizi, test automatici, Maven e pulizia dei metadati IDE. Non sono però passi attivi obbligatori finché il repository non viene esplicitamente ripreso.

## Punto di ripresa
Nessun lavoro attivo globale. Se viene riaperto per studio, scegliere un esercizio specifico e lavorare su quello senza riscrivere retroattivamente l'intera raccolta.
